# Udith Babu K N - Executive Portfolio & Desk

Welcome to the repository for my official personal portfolio and digital marketing hub.

I'm **Udith Babu K N**, a Marketing & Sales Executive and IT Business Analyst from Kerala, India (MBA in Operations & Marketing • B.Tech in IT). This site acts as a central hub for my professional experience, live production tools, and 100+ digital marketing and sales strategy articles.

## Design Concept: Executive Desk Aesthetic

- **Editorial Executive Desk UI:** Inspired by a classic executive workspace with warm parchment, rich British racing green/felt textures, brass badges, pushpins, and tactile minicom speech widgets.
- **Unified 100-Article Editorial Blog:** 100 deep-dive static HTML articles formatted in the same executive desk reading aesthetic for maximum readability, fast load times, and superior technical SEO indexing.
- **Zero-Bloat Architecture:** Stripped of heavy 3D assets and legacy dependencies, delivering instant page loads and high Lighthouse scores.

## Tech Stack

- **React 19 + Vite** for lightweight reactive UI and lightning-fast builds.
- **Vanilla CSS (shelbyStyle.css)** with semantic variables for warm paper, felt green, and brass accents.
- **Phosphor Icons** for crisp executive iconography.
- **React Helmet Async** for granular SEO metadata management.
- **Static HTML** with JSON-LD Schema markup for all 100 blog posts.

## Running Locally

1. Clone repository:
   ```bash
   git clone https://github.com/UdithBabuKN/udithbabukn.github.io.git
   cd udithbabukn.github.io
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start Vite development server:
   ```bash
   npm run dev
   ```
4. Build production bundle:
   ```bash
   npm run build
   ```

## Project Structure

- `src/components/ShelbyPortfolio.jsx`: Core executive desk portfolio component.
- `src/shelbyStyle.css`: Executive desk design system and styling tokens.
- `src/data/blogPostsData.js`: Central index and metadata for all 100 blog articles.
- `public/style.css`: Unified executive desk stylesheet for the 100 standalone blog articles.
- `public/blog/`: 100 static, SEO-optimized HTML articles.
